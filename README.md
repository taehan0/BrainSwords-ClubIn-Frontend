# BS ClubIn Frontend

BrainSwords 동아리의 행사 신청과 출석 관리를 위한 웹 서비스의 프론트엔드입니다. [BrainSwords-ClubIn-Backend](https://github.com/taehan0/BrainSwords-ClubIn-Backend)에서 제공하는 API를 사용합니다.

## 핵심 기능

- 회원가입 및 로그인
- 행사 등록 및 조회
- 행사 참가 신청 및 취소
- 신청자 및 출석 관리

## 기술 스택

- React
- TypeScript
- Vite

## 시작하기

```bash
npm install
npm run dev
```
